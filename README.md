# EA1 de Simulación — Yahtzee mediante Montecarlo

Actividad del curso de Simulación de la Institución Universitaria Digital de Antioquia.

## Objetivo

Desarrollar una simulación de Yahtzee para dos jugadores, con cinco dados de seis caras y hasta tres lanzamientos por turno, aplicando Montecarlo a las decisiones de conservación de dados.

## Estado inicial

Este primer avance conserva el cuaderno proporcionado como material de clase. Su código y sus salidas se mantienen sin cambios. Las salidas guardadas pertenecen al material recibido y no representan una validación realizada en este repositorio.

La revisión, las correcciones y las pruebas se registrarán en avances posteriores. En particular, se revisarán la puntuación, la evaluación de los lanzamientos restantes y el conteo de los dados efectivamente lanzados.

## Contenido

- `simulacion_01.ipynb`: cuaderno base del profesor.
- `.gitignore`: exclusiones de archivos temporales y entornos locales.

## Entorno y ejecución

El cuaderno contiene código Python y puede abrirse en Jupyter o Google Colab. Utiliza NumPy, pandas, Matplotlib, Seaborn y el paquete Python Graphviz. La generación de diagramas requiere además el programa Graphviz, con su ejecutable `dot` disponible en el entorno.

Para explorar el material, abrir el cuaderno en uno de esos entornos y ejecutar las celdas en orden. La última celda redefine parte del programa. Las instrucciones definitivas de instalación y ejecución se actualizarán después de validar la solución; todavía no se ha comprobado una ejecución completa de esta versión.

Cada cambio funcional se comprobará y registrará con un commit descriptivo antes de publicarlo en GitHub. El primer commit establece el punto de partida del trabajo y conserva la atribución del material recibido.
